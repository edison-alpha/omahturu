# Omah Turu

Aplikasi booking villa dan glamping di Tawangmangu.

## Fitur

- Pencarian dan filter villa/glamping
- Peta interaktif dengan route planner
- Sistem booking dan pembayaran
- Wishlist dan notifikasi

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app:
   ```bash
   npm run dev
   ```

3. Buka http://localhost:3000
